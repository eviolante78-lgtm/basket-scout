## 🔄 Come Aggiornare Senza Perdere Dati

1. **Dati al sicuro:** Salvati in `localStorage` chiave `basket_scout_data_v1` su `https://eviolante78-lgtm.github.io/basket-scout/`
2. **Aggiornamento:**
   - Sostituisci solo `index.html` con nuova versione su GitHub (Upload → Commit)
   - Se cambi `sw.js`, incrementa `CACHE_NAME = 'basket-scout-v2.0.1'`
   - Aspetta 2 minuti
   - Su tablet già installati: apri app → appare notifica aggiornamento (se implementata) o ricarica
   - **Dati restano**
